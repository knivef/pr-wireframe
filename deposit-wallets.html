The Problem
Shared addresses break attribution at scale
✕
Platforms that share one wallet address across multiple customers can't reliably attribute which payment came from whom without manual matching.
✕
Manual reconciliation of incoming crypto payments is time-consuming and error-prone at scale — a spreadsheet nightmare as volume grows.
✕
Address reuse creates privacy risks for customers and operational overhead for operators, especially across multiple chains.
How It Works
Unique address. Automatic attribution.
1
Create a customer
Via API or dashboard — PayRam generates a dedicated deposit address.
2
Customer sends funds
Customer sends any supported token to their unique address.
3
Payment attributed
PayRam detects the inbound tx and attributes it to the correct customer instantly.
4
Dashboard + webhook
Balance updates instantly. Webhook fires to your backend.

API Reference
POST /customers/{id}/wallet
A single API call creates a customer record and returns a unique deposit address object containing the address string, supported chains, and a creation timestamp. Fully idempotent — calling it twice returns the same address.
POST /customers/{id}/wallet — response object mockup
Operator Dashboard
Customer list with live balances
The dashboard shows every customer with their deposit address, current balance across chains, and last deposit date. Click any customer to see their full deposit history with txn hashes and amounts.
Customer wallet list — address, balance, last deposit columns
Webhooks
Deposit notification payload
When a deposit is detected, PayRam fires a webhook with customer ID, wallet address, token, amount, chain, and txn hash. Your backend can immediately update the customer's balance and trigger any downstream logic.
Webhook payload — deposit.confirmed event structure
Use Cases
Who uses Deposit Wallets
Exchange / Trading Platform
Assigns a deposit address to every user for incoming stablecoin top-ups. Balances update in real time with no reconciliation effort from the ops team.
Subscription SaaS
Uses customer wallets to track recurring stablecoin payments per account. No manual invoice matching — every payment is auto-attributed on arrival.
Marketplace
Gives each seller a unique address to receive payouts directly. Buyer settlements route to the right seller automatically without ops involvement.

What is a customer deposit wallet in a crypto payment system? ▲
A customer deposit wallet is a unique on-chain address assigned exclusively to one customer. When that customer sends funds to their address, the payment is automatically attributed to them in your platform — no manual matching needed.
