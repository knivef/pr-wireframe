[ ACTIVE WHEN: Quick Setup selected ]

Made for developers who want PayRam running in under 5 minutes. Do these steps in order.

[ PROGRESS INDICATOR — updates on step completion ]
1
Create your PayRam account
Your wallet address is where settlements land. Set it up before anything else.
2
Copy your API key
You'll need this in Step 3. Find it under Settings → API Keys in your dashboard.
Sign in first — your key appears here.
3
Run the install command
Paste this into your server terminal:
bash[ COPY ]
curl -sSL https://install.payram.com/quick | bash
Then set your API key as an environment variable:
bash[ COPY ]
export PAYRAM_API_KEY=your_api_key_here
The installer confirms when it's live. You'll see:
✓ PayRam is running on port 3000
4
Set your webhook URL
Go to Settings → Webhooks in your PayRam dashboard. Paste your server URL:
url[ COPY ]
https://your-domain.com/payram/webhook
PayRam will POST a signed notification to this URL every time a payment clears.
[ ACTIVE WHEN: Advanced Setup selected ]

Full control over your PayRam deployment. Covers environment configs, custom routing, and scaling options.

[ PROGRESS INDICATOR — updates on step completion ]
1
Create your PayRam account
Same as Quick Setup — your wallet address is your settlement destination.
2
Clone the PayRam server repo
bash[ COPY ]
git clone https://github.com/payram/server.git
cd server
cp .env.example .env
Open .env and fill in your credentials before continuing.
3
Configure your environment
Edit .env with the following values:
env[ COPY ]
PAYRAM_API_KEY=your_api_key
PAYRAM_WEBHOOK_SECRET=your_webhook_secret
PAYRAM_PORT=3000
PAYRAM_ENV=production
Find your API key and webhook secret under Settings → API Keys in your dashboard.
4
Install dependencies and start
bash[ COPY ]
npm install
npm run start
Expected output:
✓ PayRam server running on port 3000
✓ Webhook listener active
5
Configure custom routing (optional)
Edit config/routes.json to map PayRam's checkout flow to your own URL structure:
json[ COPY ]
{
  "checkout": "/pay",
  "success": "/thank-you",
  "cancel": "/cart"
}
6
Register your webhook
In your PayRam dashboard → Settings → Webhooks, paste:
url[ COPY ]
https://your-domain.com/payram/webhook
PayRam signs every POST with your webhook secret. Verify the signature server-side before marking orders as paid.
[ ACTIVE WHEN: MCP (Agentic) selected ]

Made for AI agents built on Lovable, v0, Bolt, Cursor, or any MCP-compatible runtime. Paste the config, deploy, done.

[ PROGRESS INDICATOR — updates on step completion ]
1
Create your PayRam account
Your wallet address is where payments land.
2
Copy your MCP server URL
Your agent needs this URL to connect to PayRam's MCP server:
url[ COPY ]
https://mcp.payram.com
Paste it into your agent's MCP config under tool servers.
3
Add PayRam to your agent prompt
Tell your AI builder to use PayRam for payments. Paste this into your project prompt or system instructions:
prompt[ COPY ]
Use PayRam as the payment tool via the MCP server at
https://mcp.payram.com.
API key: [paste your PayRam API key here]

On checkout, call the create_payment_link tool with the
cart total and currency. Redirect the user to the returned
URL. On success, call confirm_order.
No further code is needed — your agent reads the instructions and wires up the integration.
4
Deploy and test
Deploy your agent. On a test run, trigger a checkout. You should see a PayRam-hosted payment page load.
Return here and paste your deployed URL to verify the webhook is connected:
✓ Webhook connected. You're live.

Questions we actually get

Do I need a developer to integrate PayRam?+
Not always. The MCP and Shopify paths need zero code. The Quick Setup needs one terminal command. Only the Advanced path needs backend familiarity.
Can I test before going live?+
Yes. Every path supports test mode. You won't process real transactions until you switch to production credentials in your dashboard.
Which path should a non-technical founder pick?+
Start with MCP if you're building with an AI agent. Start with Shopify if you're on Shopify. If you're not sure, the Quick Setup is one command and fully reversible.
Does PayRam hold my funds?+
No. PayRam is non-custodial. Settlements go directly to your wallet address. We never touch the funds.
What if something breaks after I integrate?+
Reach out via the support channel in your dashboard. We respond to critical issues within the hour on weekdays.
