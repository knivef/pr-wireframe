The Problem

✕
Existing crypto rails still rely on custodians and intermediaries, creating settlement delays and counterparty risk.

API Reference
One call to settle a payment
A single POST /settle request with amount, currency, and destination address is all it takes. The response returns a transaction hash and settlement status immediately.
POST /settle — request body + response mockup
Multi-chain routing
Optimal network selection
PayRam evaluates gas costs, confirmation times, and network congestion across chains to route each payment optimally. You specify the currency; PayRam handles the network logic.
Multi-chain routing diagram
Webhooks
Real-time confirmation events
Every settled payment fires a webhook to your registered endpoint. The payload includes txn hash, block number, amount, and chain — everything your agent needs to proceed to the next action.
